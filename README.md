# Veille Chine du Sud

Site statique de veille économique (circonscriptions de Canton et de Chengdu).

- `index.html` est généré : modifier `src/page.html`, `assets/app.css` et `assets/app.js`, puis lancer `python3 tools/build.py`.
- `data.json` est remplacé chaque matin par la collecte automatique.
- `assets/fonts/` (Schibsted Grotesk, IBM Plex Mono) et `assets/geo/china.js` sont hébergés ici pour ne dépendre d'aucun service bloqué en Chine.
